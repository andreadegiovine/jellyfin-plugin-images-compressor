Images compressor

Recompresses the JPEG, PNG and WebP images of the folders ticked below, using the image encoder built into Jellyfin. Each file is processed only once and is replaced only if the result is smaller. The task Compress images (Dashboard → Scheduled Tasks) is queued automatically after a library scan, and can also be started manually.

Settings

Default: 80. Lower values give smaller files and lower image quality.

Folders to compress

The Jellyfin metadata folder and the folders of all libraries. Nothing is touched until a folder is ticked. Images stored next to the media files (posters, backdrops) are replaced in place.

Run history

Details of the latest runs of the Compress images task, newest first.
